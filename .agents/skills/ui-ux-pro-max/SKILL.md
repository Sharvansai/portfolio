# UI UX Pro Max — Design Intelligence Skill

The **UI UX Pro Max** skill equips the agent with professional UI/UX design intelligence, design system generation, component specifications, token architecture, and curated styles.

## Core Capabilities

1. **Design System & Token Architecture**:
   - Primitive $\rightarrow$ Semantic $\rightarrow$ Component token layers.
   - Design tokens for Tailwind CSS, CSS Custom Properties, and Figma handoffs.
   - Comprehensive spacing, typography, radius, and elevation scales.

2. **79+ Curated UI Styles & Archetypes**:
   - **Modern Dark Luxury / Antigravity**: Deep indigo/slate (#030712), electric cyan and radiant magenta glow accents, high-contrast typography, interactive particle systems.
   - **Bento Grid**: Structured responsive grid tiles with distinct hierarchies.
   - **Glassmorphism**: Layered backdrop blurs (`backdrop-blur-xl`), ultra-thin white borders (`border-white/10`), ambient radial glow.
   - **Neumorphism, Minimalist, Brutalism, Futuristic Cyberpunk, AI Native UI**.

3. **Interaction & Component Engineering**:
   - Micro-interactions, spring-physics cursor tracking, SVG mask reveals, animated border beams.
   - Accessible component patterns (contrast ratios, keyboard focus states, WCAG 2.1 AA/AAA compliance).
   - Responsive layout rules across mobile, tablet, desktop, and ultra-wide screens.

4. **Data & Scripts Directory**:
   - `data/`: Curated color palettes, font pairings, component checklists.
   - `scripts/`: Token generation and validation utilities.
   - `templates/`: Production-ready component boilerplate for React, Next.js, and Tailwind CSS.
